# Data Dictionary
restaurant.json — restaurant metadata
departments.json — departments and staffing benchmarks
categories.json — menu categories
products.json — menu, price, food cost
ingredients.json — ingredient master
recipes.json — product/ingredient recipe relationships
employees.json — staff master
sales.json — bill/order headers
sale-items.json — item-level sales
preparation.json — prepared/sold/wasted quantities
wastage.json — waste events
breakage.json — manual breakage
attendance.json — biometric-like attendance
operating-costs.json — daily variable operating costs
